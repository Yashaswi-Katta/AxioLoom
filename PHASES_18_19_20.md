## Phase 18: Symbolic Calculus Theorem Verifier & Linear Algebra Diagonalization

### 18.1 Rolle's, Lagrange's & Cauchy's Mean Value Theorem Engine (`domain/cas/CalculusTheoremAnalyzer.kt`)
- **Continuity & Differentiability Check**:
  - Evaluates denominator roots $\operatorname{Solve}(\operatorname{Denominator}(f(x)) == 0, x)$ via Symja to confirm no singularities lie inside $[a, b]$.
- **Rolle's Theorem**:
  - Confirms $f(a) = f(b)$ (tolerance $10^{-6}$), computes $f'(x) = \frac{d}{dx}f(x)$, and solves $f'(c) = 0$ for all real roots $c \in (a, b)$.
- **Lagrange's Mean Value Theorem**:
  - Computes secant chord slope $m_{\text{sec}} = \frac{f(b) - f(a)}{b - a}$.
  - Solves $f'(c) = m_{\text{sec}}$ for all interior critical points $c \in (a, b)$.
  - Emits tangent line equations $y = f(c) + m_{\text{sec}}(x - c)$ for overlay rendering.
- **Cauchy's Mean Value Theorem**:
  - Evaluates $g(a) \ne g(b)$ and computes ratio $R = \frac{f(b) - f(a)}{g(b) - g(a)}$.
  - Solves $f'(c) - R \cdot g'(c) = 0$ for $c \in (a, b)$.

### 18.2 Matrix Diagonalization, Cayley-Hamilton & Characteristic Polynomial (`domain/cas/MatrixAnalyzer.kt`)
- **Characteristic Polynomial**:
  - Computes $p(\lambda) = \det(A - \lambda I)$ via Symja `CharacteristicPolynomial(A, lambda)`.
  - Normalizes output to descending polynomial form (e.g. $\lambda^2 - 7\lambda + 10$).
- **Eigenvalues & Eigenvectors**:
  - Computes symbolic and numeric eigenvalues and corresponding modal matrix $P$ and diagonal matrix $D = \operatorname{diag}(\lambda_1, \lambda_2, \dots)$.
- **Cayley-Hamilton Theorem**:
  - Verifies $p(A) = \mathbf{0}$ by matrix polynomial substitution.
  - Generates inverse formulas from characteristic coefficients:
    $$\lambda^2 - c_1 \lambda + c_0 = 0 \implies A^{-1} = \frac{1}{c_0}(c_1 I - A)$$

## Phase 19: Discrete-Time Digital Signal Processing (DSP) Engine

### 19.1 Discrete Sequence AST & Convolution / DFT Syntax
- **AST Nodes** in `MathExpr`:
  - `DiscreteSequence(val elements: List<MathExpr>)`
  - `DiscreteConvolution(val left: MathExpr, val right: MathExpr)`
  - `CircularConvolution(val left: MathExpr, val right: MathExpr, val length: MathExpr? = null)`
  - `DiscreteFourierTransform(val expr: MathExpr, val inverse: Boolean = false)`
  - `IndexedSequence(val name: String, val index: MathExpr)` ($x[n]$)
- **Transpiler Extensions** in `LatexToSymjaTranspiler.kt`:
  - Recognizes `\{1, 2, 3\}`, `[1, 2, 3]`, $x[n]$.
  - Lexes `\ast`, `\star` as binary operator `Kind.CONV` with precedence 21.
  - Recognizes `\conv(x, h)`, `\cconv(x, h, N)`, `\dft(x)`, `\idft(X)`.
  - Compiles into closed Symja `Table` sum convolution commands.

### 19.2 Pure Kotlin Signal Engine (`domain/dsp/DiscreteSignalEngine.kt`)
- Direct linear convolution $y[n] = \sum_k x[k] h[n - k]$ with step-by-step shift-and-multiply table.
- $N$-point circular convolution with modulo index wrapping.
- Radix-2 Cooley-Tukey Decimation-in-Time (DIT) FFT with bit-reversal and exact arbitrary-$N$ DFT fallback.
- Guarantees `idft(dft(x))` round-trip accuracy within $10^{-6}$.
- Magnitude, phase, and Power Spectral Density (PSD) analysis.

### 19.3 Compose Stem / Lollipop Plot Card (`ui/canvas/DiscreteStemPlotCard.kt`)
- Renders sample stems from baseline $y = 0$ up/down to sample values with circular head markers.
- Interactive mode tabs: $x[n]$, $h[n]$, $y[n] = x * h$, $y_{\text{circ}}[n]$, $|X[k]|$.
- Touch/scrub hover cursor displaying sample index and value.
- Expandable step-by-step convolution summation table.

## Phase 20: RF Smith Chart & Pre-Built Engineering Notebook Templates

### 20.1 Vector RF Smith Chart (`ui/canvas/SmithChartCard.kt`)
- **Calculations** (`SmithChartMath`):
  - Normalized load impedance $z_L = \frac{R_L + jX_L}{Z_0} = r + jx$.
  - Voltage reflection coefficient: $\Gamma = \frac{z_L - 1}{z_L + 1} = |\Gamma| \angle \theta^\circ$.
  - Voltage Standing Wave Ratio: $\text{VSWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|}$.
  - Return Loss: $\text{RL}_{\text{dB}} = -20 \log_{10}|\Gamma|$.
  - Quarter-wave input impedance: $Z_{\text{in}}(\lambda/4) = \frac{Z_0^2}{Z_L}$.
- **Native Canvas Rendering**:
  - Constant-resistance circles ($r = 0.2, 0.5, 1.0, 2.0, 5.0$) in Gunmetal (`#252A31`).
  - Constant-reactance arcs ($x = \pm 0.2, \pm 0.5, \pm 1.0, \pm 2.0, \pm 5.0$) clipped inside unit disk.
  - Dashed constant-VSWR circle in Gold (`#FFD54F`).
  - Load marker $z_L$ in Warm Amber (`#FFB300`) and quarter-wave point $z_{\text{in}}$ in Green.
  - Interactive sliders to scrub $R_L, X_L, Z_0$ at 60fps.
